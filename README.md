# Webpack Starter Template

## Setup
```
npm install
```

## Development
```
npm run dev
```
Starts webpack-dev-server at http://localhost:3000 with live reload.

## Production build
```
npm run build
```
Outputs an optimized bundle to `dist/`.

## Deploy (GitHub Pages via subtree, optional)
```
npm run deploy
```
